# Frontend

Este módulo contendrá la interfaz de usuario del Analizador Inteligente de Consumo Energético.

## Responsabilidades previstas

- Mostrar el formulario de análisis energético.
- Capturar los datos requeridos por la API.
- Validar los campos antes de enviar la solicitud.
- Consumir el endpoint del backend.
- Mostrar estados de carga y errores.
- Presentar la categoría energética obtenida.
- Mostrar la probabilidad del modelo.
- Mostrar el costo mensual estimado.
- Presentar las recomendaciones de optimización.

## Campos iniciales del formulario

- Consumo mensual en kWh.
- Uso durante horario pico.
- Cantidad de equipos.
- Tipo de inmueble.
- Horas de uso de equipos de alto consumo.

## Estado

La tecnología o framework del frontend todavía no ha sido definido.
